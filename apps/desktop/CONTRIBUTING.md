# Contributing to the Desktop Component

Use the parent repository's [`CONTRIBUTING.md`](../../CONTRIBUTING.md). Desktop changes must retain
the MIT notice, preserve legacy data compatibility, and pass frontend, Rust, privacy, recording,
sidecar, and accessibility gates.

Do not reintroduce upstream release URLs, telemetry defaults, cloud transcript processing, direct
connector writes, or user-facing Meetily branding. `meetily` may remain only in compatibility
adapter names, legacy storage migration, and upstream attribution.
